# 2mriky Pack Bulk

الزق كلام كتير ← يطلع ملف `.md` أو `.txt` نضيف ← شير (AirDrop / Save to Files) أو تنزيل.
كل الشغل جوه المتصفح. مفيش أي نص بيترفع لأي سيرفر.

## بيعمل إيه
- **يختار النوع لوحده:** لو فيه تنسيق Markdown (عناوين `#`، `**bold**`، لينكات، جداول، ليستات) يطلع `.md`، غير كده `.txt`. تقدر تجبره.
- **يسمّي لوحده** من أول سطر، وتقدر تكتب الاسم بنفسك.
- **ينضّف:** مسافات آخر السطور، السطور الفاضية المتكررة، الرموز المخفية اللي بتيجي مع النسخ.
- **يقسّم:** عند `---` أو عند العناوين (`#` و `##`) ← كذا ملف في شير واحد، أو ZIP في التنزيل.
- **يحفظ المسودة** لو قفلت الصفحة، و**سجل** بآخر 40 ملف.
- **على اللاب:** اسحب ملف md/txt على المربع يفتحه · `⌘S` تنزيل · `⌘Enter` شير.

## الرفع على GitHub Pages
1. ريبو جديد (مثلًا `pack-bulk`) ← ارفع كل الملفات دي في الروت.
2. Settings ← Pages ← Branch: `main` / root ← Save.
3. الرابط: `https://<user>.github.io/pack-bulk/`

## على الآيفون
افتح الرابط في Safari ← زرار الشير ← **Add to Home Screen**. بيفتح زي التطبيق ويشتغل من غير نت.

## لما تعدّل
زوّد رقم النسخة `?v=N` في `index.html` (للـ css و js) وفي `sw.js` (اسم `CACHE` والـ ASSETS) عشان الكاش.
